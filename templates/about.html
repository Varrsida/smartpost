About SmartPost

AI-Powered Post Office Management and Smart Delivery System

Project Overview

SmartPost is an end-to-end web software application designed to digitally streamline core postal office operations. The platform integrates customer registration, parcel booking, automated postage calculation, dynamic shipment tracking, staff administration, complaint tracking, and operational reports.

A key innovation of SmartPost is its embedded Machine Learning module, which uses a trained Random Forest Classifier to analyze shipment characteristics (distance, weight, weather, hub workload, and holiday surge) and forecast potential delivery delays before parcels leave the counter.

AI & Machine Learning Methodology

The artificial intelligence module predicts whether a shipment will experience ON TIME delivery or a POSSIBLE DELAY based on 9 core features:

  • service_type: Postal category tier (Speed Post, Parcel, International, etc.)
  • weight: Package weight in kilograms
  • distance: Transit distance between origin and destination in kilometers
  • processing_days: Allotted hub processing timeframe
  • destination_type: Geographical classification (Urban, Rural, Remote)
  • previous_delay_rate: Historical delay probability at target hub
  • workload: Current depot package congestion index (1-10)
  • weather_risk: Environmental weather conditions (Low, Medium, High)
  • holiday_period: Festive season volume surge indicator

Note: In accordance with academic project standards, the model is trained on a synthetic dataset generated by train_model.py.

System Modules

1. Customer Management: Sender/receiver profiles, ID proof verification, address book.
2. Postal Booking: Dynamic tracking number generation, automated weight & declared value calculation.
3. Shipment Tracking: Vertical status journey timeline from booking to doorstep delivery.
4. Employee Management: Staff directory, role permissions, active/inactive status.
5. Complaints System: Customer ticket logging, priority assignment, status updates.
6. Operational Reports: Exportable analytics, revenue breakdowns, and print receipts.
